# Claude Code Plugin Marketplace

This directory is a local Claude Code plugin marketplace.

For the Windows workbench, follow the [user guide](../README.md). Its portable package includes the plugin; the steps below are for standalone Claude Code installation.

Available plugin:

- `ai-startup-compliance-review`

Install flow:

```text
/plugin marketplace add /path/to/ai-compliance-review/claude-code-plugin
/plugin install ai-startup-compliance-review@ai-compliance-review-local
```

Then restart Claude Code.
